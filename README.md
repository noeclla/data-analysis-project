Predicting Academic Performance from Screen Time and Lifestyle Factors Using Machine Learning 

Overview:
This project analyzes the relationship between screen time, lifestyle habits, and academic performance among university students using Machine Learning.

Objectives:
- Analyze the impact of screen time on academic performance.
- Study the influence of sleep and attendance.
- Compare different Machine Learning models.
  
Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- XGBoost
  
Methods
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning Model Training
- Model Evaluation
  
Results:
XGBoost achieved an R² score of 0.9403, while the Stacking Ensemble achieved approximately 0.9531 in the reported experiments.

Files
- Data_project.ipynb: Main analysis and machine learning code (step by step).
- project_report.pdf: (academic report).
